# Batch 2B-1：TodaySheet、提醒日程与通知边界规格

## 1. TodaySheet 体验原则

- **入口与唤起**：TodaySheet 不是一个独立的页面，而是从屏幕顶部或左侧边缘“揭开”的一层半透明质感纸页。它像是一张放在温室木桌上的晨报，通过点击顶栏的“日光刻度”或向下滑动唤起。
- **层级关系**：
    - **顶层 (The Light)**：今日概览（天气、心情、今日寄语）。
    - **中层 (The Flow)**：时间线（Timeline），以流动的光斑表示过去与未来的连接。
    - **底层 (The Traces)**：提醒与日程，它们是时间的痕迹，而非待办清单。
- **去效率工具感**：
    - 严禁使用复选框（Checkbox）。使用“点亮/熄灭”或“划线抹除”的交互。
    - 严禁使用紧凑表格。使用错落有致的“晶格”布局，留白率保持在 40% 以上。
    - 字体使用非衬线体，但数字采用等宽衬线字体，营造一种“手工记录”的精密感。

---

## 2. 组件规格：TodaySheet

- **职责**：聚合展示今日状态、历史轨迹与未来安排，作为用户进入系统的“定心丸”。
- **DOM 建议**：
  ```html
  <section id="today-sheet" class="glass-overlay">
    <header class="sheet-header"> <!-- 今日概览 --> </header>
    <div class="sheet-content">
      <aside class="timeline-track"> <!-- 时间线 --> </aside>
      <main class="events-grid"> <!-- 提醒与日程 --> </main>
    </div>
  </section>
  ```
- **API 映射**：
    - 初始化：并发请求 `GET /api/today` 与 `GET /api/timeline`。
    - 实时性：每 5 分钟静默刷新一次，或在用户重新聚焦窗口时刷新。
- **状态定义**：
    - **默认**：磨砂玻璃背景，内容随滚动轻微位移（Parallax）。
    - **加载**：骨架屏采用脉冲式的呼吸光效（Pulse Glow）。
    - **空状态**：显示“今日无事，宜采集阳光”，配以极简的植物剪影。
- **交互**：
    - 点击非内容区域：向上收起。
    - 左右滑动：在“今日”与“昨日总结”之间切换。
- **移动端**：全屏覆盖，底部保留 80px 的触控关闭区。
- **验收标准**：展开动画耗时 400ms，曲线为 `cubic-bezier(0.22, 1, 0.36, 1)`（由快到慢的平滑开启）。

## 3. 组件规格：Scheduling & Reminder Layer

- **提醒 (Reminder)**：
    - **交互**：点击提醒项触发“光晕菜单”。
    - **Snooze**：提供“一刻钟后”、“傍晚”、“明晨”选项，而非具体的分钟输入。
    - **Complete**：点击后，文字颜色变浅并伴随微小的粒子散开效果，不立即消失，刷新后移入历史。
- **日程 (Calendar Event)**：
    - **视觉**：跨度较长的日程在时间轴上表现为一段连续的“透光色带”。
    - **冲突处理**：重叠的日程不堆叠，而是并排缩小宽度，形成交错的晶格。
- **创建流**：
    - 采用“自然语言输入行”：`[ 提醒我 18:00 浇花 ]`。
    - 弱网处理：提交后 UI 立即进入“半透明待确认”状态，API 失败后显示“痕迹未留存，点击重试”。
- **移动端**：调用原生时间选择器，但样式通过 CSS 变量模拟晶格质感。

---

## 4. 组件规格：NotificationBoundary

- **设计理念**：通知不是打扰，而是边界的提醒。
- **DND (勿扰模式)**：
    - 视觉：全屏边缘出现极细的深蓝/暗金渐变边框。
    - 交互：提供“呼吸空间”按钮，点击后 30 分钟内屏蔽所有非紧急通知。
- **Quiet Hours (静默时间)**：
    - 自动触发时，所有通知进入“静默池”，TodaySheet 上显示一个“月亮”图标及堆叠计数。
- **Daily Limit (每日上限)**：
    - 当今日通知超过 `daily_limit`，系统会弹出一封“温柔的信”，建议用户减少交互。
- **权限缺失**：
    - 在 TodaySheet 顶部显示非侵入式的 Banner：“浏览器通知已关闭，光影将无法穿透屏幕。”

## 5. 核心流程：查看今日与时间线

1.  **触发**：用户点击 Header 的日期。
2.  **UI 响应**：`#today-sheet` 从 `translateY(-100%)` 变为 `0`。
3.  **API 调用**：
    - `GET /api/today` -> 渲染天气、心情摘要。
    - `GET /api/timeline` -> 渲染时间线节点。
4.  **渲染逻辑**：
    - 历史节点（Past）：低对比度，去色。
    - 当前节点（Present）：带呼吸灯光晕。
    - 未来节点（Future）：虚线边框，半透明。

---

## 6. 核心流程：添加提醒/日程与修改通知偏好

- **添加流程**：
    1. 点击 `+` 按钮，弹出极简输入框。
    2. 输入内容，按 Enter。
    3. `POST /api/reminders` 发起。
    4. 成功：项从输入框位置下落到时间轴对应位置。
    5. 失败：输入框抖动，提示“网络波动，痕迹消散”。
- **设置流程**：
    1. 进入 `Notification Settings` 模态窗。
    2. 修改 `allowed_kinds`（允许的通知类型）。
    3. `PATCH /api/settings/notifications`。
    4. 实时生效，无须保存按钮（Auto-save with debounce）。

| 状态 ID | 视觉表现 | 文案建议 | 可操作项 |
| :--- | :--- | :--- | :--- |

| `today-error` | 灰调的磨砂玻璃 | 光影连接暂时中断。 | 点击重试 |
| `timeline-empty` | 垂直虚线 | 时间线尚是一片空白。 | 开启记录 |
| `reminder-due` | 橙色柔光闪烁 | 此时此刻：[任务名] | 完成 / 稍后 |
| `reminder-snoozed`| 蓝色半透明标签 | 已推迟至傍晚。 | 取消推迟 |
| `reminder-completed`| 文字中划线，透明度 0.3 | 痕迹已留存。 | 撤销 |
| `reminder-cancelled`| 灰色斜纹背景 | 计划已取消。 | 删除 |
| `calendar-empty` | 空白的晶格块 | 暂无日程安排。 | 预约时间 |

| `dnd` | 全屏边缘暗色调 | 栖光处于静谧模式。 | 结束静谧 |
| `quiet-hours` | 侧边栏月亮图标 | 晚安，通知已静默。 | 查看静默消息 |
| `daily-limit` | 柔和的黄色警告 | 今日交互已达上限，建议休息。 | 忽略 |
| `settings-saving` | 旋转的小光点 | 正在同步偏好... | 无 |
| `settings-error` | 红色微弱边框 | 偏好未能保存。 | 重新同步 |

## 8. Batch 2B-1 自检清单

1.  [ ] TodaySheet 展开时，背景是否有高斯模糊（backdrop-filter）？
2.  [ ] 时间线上的节点是否根据 `api/timeline` 的时间戳准确排序？
3.  [ ] 点击“完成”提醒时，是否有粒子散开的过渡动画？
4.  [ ] 移动端下划关闭 TodaySheet 是否顺畅？
5.  [ ] 勿扰模式（DND）开启后，UI 是否有明显的“降噪”处理？
6.  [ ] API 返回 404 或 500 时，是否显示了“光影中断”的优雅错误态？
7.  [ ] 快速连续点击“完成”按钮，是否有防抖处理？
8.  [ ] 日程冲突时，两个日程块的宽度是否自动各占 50%？
9.  [ ] 浏览器禁用通知权限时，系统内是否有相应的引导提示？
10. [ ] Snooze 选项是否符合“非精确时间”的原则（如“一刻钟”而非“15分钟”）？
11. [ ] 所有的文字颜色对比度是否符合 Web 可访问性标准，即使在磨砂背景下？
12. [ ] 静态 index.html 中的 JS 是否正确处理了 API 的异步等待状态？
