# 叶筝主页面前端实现说明

> 文档版本：V1.2  
> 实现对象：叶筝情感陪伴产品主页面  
> 对应设计规范：`01-叶筝主页面-UI设计规范-V1.2.md`  
> 参考设计图：`reference-main-ui-v1.1.png`

---

## 1. 实现目标

本页面实现应满足以下要求：

1. 使用单页沉浸式布局，不使用抽屉或传统底部导航。
2. 角色立绘作为全屏主视觉。
3. 主页面中部为**滚动式对话文本区**，展示最近几句对话。
4. 对话内容不得使用左右气泡或头像列表。
5. 今日、记忆、来信、心迹以页面上半部两侧悬浮图标呈现。
6. 人物状态面板作为主页面核心内容之一。
7. 底部输入区是唯一明确的一级操作。
8. 支持移动端响应式、安全区、软键盘和减少动态模式。

## 5. 推荐页面骨架

```tsx
export function CompanionHome() {
  const [message, setMessage] = useState("");
  const [isSending, setIsSending] = useState(false);
  const reducedMotion = useReducedMotion();

  const { data, loading } = useCompanionHomeData();

  async function handleSubmit() {
    const content = message.trim();
    if (!content || isSending) return;

    setIsSending(true);
    try {
      await sendCompanionMessage(content);
      setMessage("");
    } finally {
      setIsSending(false);
    }
  }

  if (loading) return <CompanionHomeSkeleton />;

  return (
    <main
      className={styles.page}
      data-reduced-motion={reducedMotion || undefined}
    >
      <AmbientBackground scene={data.scene} />
      <CompanionHero portrait={data.companion.portrait} />

      <TopSceneHeader
        scene={data.scene}
        companion={data.companion}
      />

      <FloatingNav
        side="left"
        items={data.entries.filter(item => item.side === "left")}
      />
      <FloatingNav
        side="right"
        items={data.entries.filter(item => item.side === "right")}
      />

      <section className={styles.centerLayer}>
        <ConversationStream
          items={data.conversation.items}
          hasMoreAbove={data.conversation.hasMoreAbove}
          hasMoreBelow={data.conversation.hasMoreBelow}
        />
        <CompanionStatusPanel items={data.companion.statusItems} />
      </section>

      <CompanionComposer
        value={message}
        disabled={isSending}
        onChange={setMessage}
        onSubmit={handleSubmit}
      />
    </main>
  );
}
```

## 8. 动态效果实现架构（V1.2 核心新增）

## 8.1 组件结构

```tsx
<EffectsOrchestrator
  intensity={effectIntensity}
  scene={data.scene.theme}
  paused={documentHidden}
>
  <AmbientBackground scene={data.scene} />
  <ParticleField density="adaptive" />
  <LightCaustics />
  <PointerGlow />
  <WaterRippleLayer ref={rippleRef} />
  <CompanionHero portrait={data.companion.portrait} />
</EffectsOrchestrator>
```

`EffectsOrchestrator` 负责：

- 读取 `prefers-reduced-motion`；
- 根据设备性能决定粒子密度；
- 页面进入后台时暂停动画；
- 管理“静谧 / 标准 / 绮丽”三档强度；
- 控制入场编舞与空闲编舞；
- 保证同一时刻不会触发过多高亮效果。

## 8.3 页面可见性控制

```ts
export function useDocumentVisibility() {
  const [hidden, setHidden] = useState(document.hidden);

  useEffect(() => {
    const update = () => setHidden(document.hidden);
    document.addEventListener("visibilitychange", update);

    return () => {
      document.removeEventListener("visibilitychange", update);
    };
  }, []);

  return hidden;
}
```

页面隐藏后：

- 暂停 Canvas 绘制；
- 暂停 CSS 动画；
- 停止空闲编舞计时器；

## 10. Canvas 粒子系统

## 10.1 使用场景

Canvas 适合：

- 星尘；
- 浮游光点；
- 近景虚焦粒子；
- 少量雨丝。

不建议用 DOM 创建数百个粒子。

## 10.2 粒子数据

```ts
interface Particle {
  x: number;
  y: number;
  radius: number;
  opacity: number;
  speedX: number;
  speedY: number;
  depth: 0 | 1 | 2;
  phase: number;
}
```

## 10.3 核心绘制循环

```ts
function drawFrame(time: number) {
  if (paused) {
    frameId = requestAnimationFrame(drawFrame);
    return;
  }

  const dpr = Math.min(window.devicePixelRatio || 1, 2);
  context.clearRect(0, 0, width * dpr, height * dpr);

  for (const particle of particles) {
    particle.x += particle.speedX;
    particle.y += particle.speedY;

    const flicker =
      0.82 + Math.sin(time * 0.0007 + particle.phase) * 0.18;

    context.globalAlpha = particle.opacity * flicker;
    context.beginPath();
    context.arc(
      particle.x * dpr,
      particle.y * dpr,
      particle.radius * dpr,
      0,
      Math.PI * 2
    );
    context.fill();
  }

  frameId = requestAnimationFrame(drawFrame);
}
```

## 10.4 自适应密度

```ts
function getParticleCount(
  width: number,
  height: number,
  density: number
) {
  const area = width * height;
  const base = Math.round(area / 18_000);

  const lowMemory =
    "deviceMemory" in navigator &&
    Number(navigator.deviceMemory) <= 4;

  const factor = lowMemory ? 0.55 : 1;

  return Math.max(
    12,
    Math.min(90, Math.round(base * density * factor))
  );
}
```

## 10.5 模糊近景粒子

近景粒子数量应很少，可单独绘制在第二个 Canvas 中，并使用 CSS `filter: blur()`，避免每粒子单独做昂贵阴影。

## 17. 空闲编舞调度

```ts
type IdleEvent =
  | "blink"
  | "jewelShimmer"
  | "shootingStar"
  | "tinyRipple"
  | "letterGlow";

const IDLE_EVENTS: IdleEvent[] = [
  "blink",
  "jewelShimmer",
  "shootingStar",
  "tinyRipple",
  "letterGlow",
];

function scheduleIdleEvent() {
  const delay = 20_000 + Math.random() * 20_000;

  return window.setTimeout(() => {
    const event =
      IDLE_EVENTS[Math.floor(Math.random() * IDLE_EVENTS.length)];

    runIdleEvent(event);
    scheduleIdleEvent();
  }, delay);
}
```

规则：

- 用户刚操作后重新计时；
- 页面不可见时停止；
- 每次只运行一个事件；
- 同一事件不得连续出现两次。

## 18. 性能与降级

### 18.1 性能预算

建议：

- Canvas 粒子数量：标准模式 25–55，绮丽模式 50–90；
- 同时执行的持续 CSS 动画：不超过 8 个；
- 使用 `will-change` 的元素：不超过 6 个；
- 大面积 `backdrop-filter`：不超过 5 个组件；
- `devicePixelRatio` 上限：2；
- 页面后台时动画全部暂停。

### 18.2 自动降级

满足任一条件时降低到标准或静谧：

- `prefers-reduced-motion: reduce`；
- `navigator.deviceMemory <= 4`；
- 持续帧率低于 45 FPS；
- 页面开启省电模式（若平台可检测）；
- WebGL/Canvas 初始化失败。

### 18.3 帧率监测

```ts
function createFpsMonitor(onLowFps: () => void) {
  let frames = 0;
  let startedAt = performance.now();

  function tick(now: number) {
    frames += 1;

    if (now - startedAt >= 2000) {
      const fps = (frames * 1000) / (now - startedAt);

      if (fps < 45) {
        onLowFps();
      }

      frames = 0;
      startedAt = now;
    }

    requestAnimationFrame(tick);
  }

  requestAnimationFrame(tick);
}
```

不要频繁升级和降级。一次会话中降级后维持当前档位。

## 24. 软键盘与滚动协调

### 12.1 键盘弹出时

- `ConversationStream` 高度可适当压缩；
- `CompanionStatusPanel` 保持可见，必要时上移；
- 四个悬浮入口可降低透明度或暂时隐藏；
- 输入区始终保持在安全区域之上。

### 12.2 避免双重滚动冲突

主页面根节点不应滚动；仅文本流局部滚动。

需要确保：

- 触摸文本区时滚动文本；
- 非文本区不触发页面整体滚动；
- 输入聚焦后软键盘不导致整页抖动。
