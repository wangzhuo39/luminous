# Batch 3B Supplement：`/api/jobs` 后台任务审计映射

## 1. 挂载位置与默认隐藏策略
*   **挂载位置**：无缝集成于 `DebugTracePanel`（调试追踪面板）的底部抽屉或右侧边栏中，作为独立的 “Jobs Audit” Tab 存在。
*   **隐藏策略**：默认处于 **DOM 级销毁状态**。仅当满足开发者唤醒条件（如 URL 携带 `?sys_debug=true` 或在设置页连续点击版本号 7 次）时，才动态加载并渲染该模块，避免污染正常用户的 DOM 树。

## 2. 任务状态视觉与交互映射
针对 `/api/jobs` 返回的 `status` 字段，执行以下精确的视觉映射：
*   **Running (执行中)**：`#1890FF`（栖光蓝）。左侧 icon 使用匀速旋转的 Spinner，背景辅以极弱的呼吸高光。
*   **Success (已成功)**：`#52C41A`（成功绿）。显示实心 Check icon，并附加淡入的完成时间戳（如 `in 2.3s`）。
*   **Failed (已失败)**：`#FF4D4F`（警示红）。状态栏高亮，**支持点击展开**，展示下发的 `error_message` 或 Stack Trace 缩略信息。
*   **Queued (排队中)**：`#FAAD14`（琥珀黄）或中性灰。使用虚线边框或沙漏 icon，表示任务已入队但未被 Worker 消费。
*   **Stale / Unknown (僵死/未知)**：`#722ED1`（暗紫）或带有 `?` 徽标的灰色。用于标识超时、失去心跳或 Worker 意外崩溃的孤儿任务。

## 3. 与 `/api/trace`、`/api/ledger` 的上下文联动
*   **Trace 联动 (链路追踪)**：在 Job 详情卡片中，若存在 `trace_id`，提供「查看执行链路」快捷按钮。点击后面板自动切换至 Trace Tab，并以该 `trace_id` 为过滤条件重新请求 `/api/trace`。
*   **Ledger 联动 (账本对账)**：若该后台任务涉及积分、权益或资产结算（如包含 `ledger_tx_id`），在卡片底部生成「审计账本」超链接，点击跳转至 Ledger 视图并高亮对应流水，实现“任务 -> 链路 -> 资金”的闭环审计。

## 4. 权限与入口规则
*   **普通用户隔离**：前端鉴权层强拦截。若当前用户 `role` 为普通用户，即使强行注入 debug 参数，前端请求拦截器也会直接 Block 对 `/api/jobs` 的请求，确保零数据泄露。
*   **开发/审计可见**：需满足 **双重校验**：当前用户 Token 解析包含 `admin`、`developer` 或 `auditor` 角色，**且**前端处于 Debug 模式，方可解锁入口并正常发起请求。

## 5. 错误与弱网状态处理
*   **弱网降级**：当 `/api/jobs` 请求延迟超过 2000ms 时，列表区平滑过渡为骨架屏（Skeleton），并显示「正在同步队列状态...」的微提示，避免用户误判为 UI 卡死。
*   **错误阻断**：若接口返回 403（权限失效）或 5xx（队列服务宕机），触发局部 Error Boundary。面板内显示轻量级断态组件（如“无法连接到任务调度中心”），并提供「手动重试」按钮，**绝不能**导致整个 `DebugTracePanel` 崩溃。

## 6. 体验与工程自检清单 (Checklist)
- [ ] **轮询销毁**：切换离开 Jobs Tab 或关闭 `DebugTracePanel` 时，必须清除 `/api/jobs` 的短轮询定时器（或中止 SSE 链接）。
- [ ] **视觉验收**：5 种 Job 状态的颜色、Icon 及动画严格遵循上述规范，暗黑模式下色彩对比度符合 WCAG AA 标准。
- [ ] **越权测试**：使用普通测试账号登录，强制开启 Debug 面板，验证 Network 中无 `/api/jobs` 请求发出。
- [ ] **联动传参**：验证从 Job 卡片跳转至 Trace / Ledger 时，上下文 ID 参数传递准确无误，无白屏现象。
- [ ] **容错测试**：通过 DevTools 模拟 Offline 或 Slow 3G，确认骨架屏及局部重试机制按预期工作。
