# 栖光前端用户操作手册 v1

> 本手册说明当前前端的入口层级、各入口对应的能力，以及用户完成常见操作的路径。

## 1. 首屏结构

栖光首屏由四部分组成：

1. **对话字幕区**：与栖光交流，恢复最近历史，并在发送后显示实时回应。
2. **凝露式输入区**：输入消息，按发送按钮或按 Enter 发送；Shift+Enter 换行。
3. **一级空间入口**：今日、记忆、隐私、来信。
4. **环境状态层**：通过光线、雾感和微光表达连接、忙碌、离线或安静状态。

任务、日记、日历、提醒、活动和日常不会抢占首屏，它们从“今日”空间的“更多生活流”进入。

## 2. 一级入口总览

### 2.1 今日

**用途**：查看今天的生活全景和时间线，是生活能力的总入口。

打开“今日”后可以看到：

- 今日摘要：当天需要关注的事项、提醒和状态。
- 更多生活流：展开二级入口。
- 时间线：按时间回顾今天已经发生或即将发生的内容。

“今日”适合每天开始或结束时使用，也适合快速确认今天有哪些需要照看的事情。

### 2.2 记忆

**用途**：查看栖光保存的共同记忆，并管理记忆内容。

记忆空间支持：

- 搜索和浏览记忆。
- 查看记忆关联的主题、链接和证据。
- 修改记忆文字。
- 让某条记忆进入遗忘流程。
- 导出个人数据。

编辑适用于修正事实或表达方式；遗忘适用于不希望继续保留的内容。遗忘前应确认目标记忆，避免误操作。

### 2.3 隐私

**用途**：管理本地数据、通知偏好和陪伴边界。

隐私空间支持：

- 查看当前隐私与数据说明。
- 设置通知是否启用。
- 设置每日联系上限。
- 设置勿扰时段。
- 保存隐私偏好。

当通知关闭或处于勿扰时段时，系统仍可保存生活数据，但不会主动打扰。

### 2.4 来信

**用途**：查看栖光主动留下的消息。

来信空间支持：

- 查看未读和历史主动消息。
- 标记已读。
- 对消息进行有帮助、一般或不需要等反馈。
- 在需要时重试加载。

来信是“被动收到的陪伴”，不等同于对话输入。用户可以阅读后再决定是否回复或继续聊天。

## 3. 今日下的二级入口

打开“今日”并展开“更多生活流”，可以进入以下能力：

### 3.1 活动

**用途**：记录一段需要投入时间的活动，例如散步、阅读、专注或共同计划。

常用操作：

1. 选择“活动”。
2. 点击“计划一次活动”。
3. 填写活动名称和类型。
4. 保存后，在活动列表中开始、完成或取消。

活动适合描述一段时间，而不是一个瞬间任务。

### 3.2 日记

**用途**：记录某一天的较完整文字，包括当天的感受、事件或回顾。

常用操作：

1. 选择“日记”。
2. 新建或打开某一天的日记。
3. 填写标题和正文。
4. 保存、编辑或删除日记。

日记是用户主动写下的内容，不会自动等同于记忆。需要长期保留的事实，可以另外整理到记忆空间。

### 3.3 提醒

**用途**：记录未来某个时间需要被提醒的事情。

常用操作：

1. 选择“提醒”。
2. 创建提醒并填写标题、时间和可选说明。
3. 在列表中完成、取消或延后提醒。

延后适用于事情仍然要做但当前时间不合适的情况；取消表示不再需要提醒。

### 3.4 日历

**用途**：记录有明确时间范围或日期范围的事件。

常用操作：

1. 选择“日历”。
2. 创建日历事件。
3. 设置全天事件或开始、结束时间。
4. 保存后编辑或删除事件。

日历适合会议、预约、行程等有时间结构的内容；简单的待办事项优先使用任务。

### 3.5 任务

**用途**：记录一个可以完成或归档的行动。

常用操作：

1. 选择“任务”。
2. 新建任务，填写标题、说明、优先级和可选截止时间。
3. 点击任务查看详情。
4. 完成任务，或在不需要时归档。

任务适合“需要做什么”；日历适合“什么时候发生”。两者可以同时使用，但不必重复创建。

### 3.6 日常

**用途**：记录重复发生的习惯或例行安排。

常用操作：

1. 选择“日常”。
2. 新建日常并选择重复周期。
3. 在当天完成一次打卡。
4. 暂停、恢复或停用日常。

暂停适用于暂时不想执行但未来可能恢复的日常；停用表示结束这项日常。

## 4. 对话中的行动确认

当栖光识别出需要修改生活数据的行动时，会先显示 **Action Preview**，不会直接执行。

操作流程：

1. 阅读行动摘要和目标对象。
2. 确认内容无误后选择“确认”。
3. 如果不想执行，选择取消或关闭。
4. 执行成功后，到对应的任务、提醒、日历或日常入口查看结果。

行动预览是对创建、完成、开始或打卡等操作的二次确认。聊天中的建议不会自动改变生活数据。

## 5. 常见使用路径

### 每天早上

`今日 → 查看摘要 → 展开更多生活流 → 查看提醒/日历 → 回到对话`

### 记录一件未来要做的事

`今日 → 任务 → 新建任务 → 设置优先级或截止时间 → 保存`

### 记录固定习惯

`今日 → 日常 → 新建日常 → 选择周期 → 每天打卡`

### 回顾并整理共同记忆

`记忆 → 搜索或浏览 → 查看关联信息 → 编辑或遗忘`

### 查看栖光主动联系

`来信 → 阅读消息 → 标记已读 → 选择反馈`

### 管理打扰边界

`隐私 → 设置通知、每日上限和勿扰时段 → 保存`

## 6. 状态与异常

- **加载中**：空间正在请求数据，保持当前页面即可。
- **空状态**：当前没有记录，可以直接创建第一项内容。
- **离线或超时**：页面会保留当前内容，网络恢复后可重试。
- **每日上限**：系统会克制地提示今日主动联系额度已用完，不影响查看历史和手动聊天。
- **保存失败**：先检查输入内容和网络，再点击重试；重复点击不会创建重复数据。

## 7. 数据边界

- 对话、记忆和生活流数据以服务端持久化结果为准。
- 浏览器页面不展示内部 trace、模型思考或原始数据库字段。
- 需要长期保存的内容使用记忆；只想留下当天记录时使用日记。
- 涉及创建、修改、完成、遗忘或删除的操作，应以页面确认结果为准。
