# 01 Design Contract

## 主方向

方案名称：晶格温室 The Crystal Solarium。

首屏应该像一个安静的、拥有纵深光窗的半透明伴侣空间。光线代表时间与情绪，记忆是晶体或光痕，主动联系是窗边信笺或流光，输入像水面凝露。

## 首屏必须成立的画面

- 用户第一眼看到的是人物、空间、光和字幕，不是工具栏。
- 人物主体是视觉中心。
- 对话以字幕或空气浮层呈现，不使用密集聊天气泡。
- 输入区弱化为底部凝露式输入，聚焦后展开。
- 功能入口是环境物件，不是显性侧边栏。

## 禁止项

- 三栏工具台
- 左侧会话列表
- 右侧卡片墙
- 顶部 SaaS 导航
- 密集聊天气泡流
- 大面积蓝紫渐变
- 浮夸玻璃拟态
- 营销落地页
- 圣经、天平、审判、圣女、宗教/法庭道具
- 叶筝专属身份文案

## 可以使用的通用物件语言

- 光窗
- 水面
- 晶体
- 信笺
- 时间刻度
- 雾面帘
- 呼吸光
- 纱质层
