# Batch 3A Supplement：390x844 移动端与 DND 勿扰状态

作为「栖光 luminous」的主设计师，针对 Batch 3A 的体验重构，现补充以下两个核心场景的具体验收规格。请前端团队严格对齐。

## 1. 390x844 移动端验收规格

基于基准设备（如 iPhone 12/13/14 等 390x844 逻辑像素机型），确保沉浸感与交互可用性。

*   **Safe-area (安全区)**：
    *   顶部需预留 `47px`（刘海/灵动岛避让），底部预留 `34px`（Home Indicator 避让）。
    *   **不可接受**：任何可交互元素（按钮、输入框）侵入安全区。
*   **首屏人物 (Avatar/Character)**：
    *   **尺寸/比例**：占据屏幕中上部，高度占比保持在 `45% - 55%`（约 380px - 460px）。
    *   **不可接受**：人物面部被顶部安全区裁切，或被底部的字幕/输入框遮挡超过胸部以上位置。
*   **字幕 (Subtitles)**：
    *   **布局**：固定于 AirInput 上方 `16px` 处。最大显示 2 行，超出则尾部省略（`...`）或平滑向上滚动。
    *   **不可接受**：单行字数过少导致频繁换行；文字与背景对比度低于 4.5:1。
*   **AirInput (输入区)**：
    *   **尺寸**：默认高度 `48px`，圆角 `24px`，悬浮于底部安全区上方 `16px`。
    *   **键盘打开状态**：键盘弹起时，AirInput 必须**无延迟贴合**键盘顶部推起。此时首屏人物需触发 `scale(0.85)` 的缩小或上移缓动，腾出空间。
    *   **不可接受**：键盘遮挡输入框；推起动画卡顿或出现白色闪烁底图。
*   **入口物件 (Entry Objects)**：
    *   **布局**：统一收纳于屏幕右上角（安全区下 `12px`，右侧 `16px`），图标尺寸 `32x32px`。
*   **Bottom Sheet (底部面板)**：
    *   **尺寸**：展开高度最高不超过视口的 `85%`（约 717px）。必须包含 `4x36px` 的顶部拖拽指示条（Drag Handle）。
    *   **不可接受**：展开时没有半透明黑色遮罩（Scrim，透明度 40%）；无法通过向下轻扫（Swipe down）关闭。

## 2. DND / 勿扰状态验收规格

当系统触发 `DND`、进入 `quiet hours`（静默时段），或触达 `daily_limit`（每日交互上限）时，界面需进入低功耗、低打扰的「静息态」。

*   **PresenceHalo (人物光晕/状态环)**：
    *   **视觉**：从活跃的呼吸渐变色切换为**低明度、单色（如深灰或暗夜蓝）、极缓呼吸**（周期 > 6s）或完全隐藏。
    *   **不可接受**：在 DND 期间仍有高频闪烁或高饱和度色彩。
*   **OutboxGlint (发送意图闪烁)**：
    *   **视觉与行为**：强制抑制（Suppressed）。当用户在 DND 期间输入时，取消发送按钮的强发光引导，改为基础的微弱描边。
*   **NotificationBoundary (通知边界)**：
    *   **行为**：拦截所有常规气泡和弹窗。**仅当**消息类型属于 `allowed_kinds`（如：系统级危机预警、用户设定的强提醒）时，才允许以极简纯文本形式在顶部安全区下方滑出。
    *   **不可接受**：伴随任何非 `allowed_kinds` 的震动反馈（Haptics）或提示音。
*   **TodaySheet (今日面板)**：
    *   **文案与视觉**：顶部需明确展示状态标签（如 🌙 *“栖光已进入静默时段”* 或 🛑 *“今日交互已达上限”*）。
    *   **可操作项**：允许用户查看历史记录、修改设置。
    *   **不能做什么**：禁用（Disable）或隐藏发起新对话的主 CTA 按钮；禁止在面板内自动播放任何音视频。

## 3. 补充自检清单 (Checklist)

前端提交 PR 前，请对照以下 10 点完成走查：

- [ ] 1. 在 390x844 模拟器下，顶部刘海和底部小黑条无任何元素穿透重叠。
- [ ] 2. 呼出键盘时，AirInput 顺滑推起，首屏人物未被遮挡面部且有合理的避让动画。
- [ ] 3. 字幕在极端长文本输入下，最多只显示 2 行，未发生布局崩塌。
- [ ] 4. Bottom Sheet 展开时背景遮罩生效，且支持手势下拉关闭。
- [ ] 5. 触发 `quiet hours` 时，PresenceHalo 立即切换至低频暗色呼吸态。
- [ ] 6. 处于 DND 状态下，尝试发送消息时 OutboxGlint 无高亮闪烁。
- [ ] 7. 模拟非 `allowed_kinds` 通知推入时，NotificationBoundary 成功将其拦截，界面无视觉干扰。
- [ ] 8. 触达 `daily_limit` 后，TodaySheet 出现明确的限制文案，且核心互动按钮置灰不可点。
- [ ] 9. DND 状态下，全局物理震动（Haptics）和音效已被完全静音（`allowed_kinds` 除外）。
- [ ] 10. 检查所有入口物件（右上角）在键盘弹起和 Bottom Sheet 展开时，层级（z-index）处理正确，未发生异常穿透。
